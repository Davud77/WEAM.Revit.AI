# WEAM.Revit.AI — 0.9.6

<img src="plugin/Assets/weam-ai.png" alt="WEAM AI" width="96" />

Надстройка Autodesk Revit 2026 и локальный MCP-сервер. AI-клиент вызывает инструменты по stdio; Node.js передаёт запросы на 127.0.0.1:37651; C# выполняет Revit API через ExternalEvent. Элементы создаются средствами Revit API и остаются редактируемыми.

## Статус публикации и лицензия

Экспериментальная версия для Revit 2026. Собственный код проекта распространяется под **GNU Affero General Public License v3.0** (`AGPL-3.0-only`); полный текст — [LICENSE](LICENSE). Сторонние зависимости сохраняют свои лицензии.

Библиотеки Autodesk, локальные токены, настройки пользователя и файлы моделей не входят в исходники. Revit должен быть установлен отдельно.

## Порядок работы

1. Откройте проект в Revit и вызовите get_project_info. revit_ping возвращает pluginVersion.
2. Прочитайте типы, параметры, координаты и опоры. Размеры в именах типов могут отличаться от фактических.
3. Вызовите preview нужной операции. Новые инструменты действительно выполняют пробное изменение и откатывают группу транзакций. Возвращаемые ID новых объектов являются временными.
4. Вызовите соответствующий apply с planId. При autoConfirm=true команда выполняется без окна. Иначе нажмите Yes в Revit; отказ выбран по умолчанию. После любого изменения документа потребуется новый preview.
5. Проверьте созданные ID, параметры, площади и вид в Revit. Сохраните проект.

План привязан к открытому документу и его ревизии, живёт 10 минут и проверяется повторно перед выполнением. Перезапуск Revit удаляет планы. Отмена MCP закрывает TCP-соединение; перед commit проверяется отмена. Ответ applied=true выдаётся только после успешного commit.

### Автоподтверждение (с 0.9.1)

Настройка хранится в `%LOCALAPPDATA%\WEAM.Revit.AI\settings.json`: `{"autoConfirm":true}`. Она перечитывается перед каждой операцией. Вкладка **WEAM AI → Авто подтверждение** переключает режим без перезапуска. `revit_ping` возвращает `autoConfirm`.

Для установки сразу с включённым режимом: `./install.ps1 -EnableAutoConfirm`. Обычная установка сохраняет существующие настройки; если файла нет, используется ручное подтверждение. Автоматический режим распространяется на все apply, включая удаление и SaveAs. Требования preview, planId, проверки ревизии документа, транзакций и отдельного allowDependentDeletion остаются. Собственные окна ошибок Revit и запросы других надстроек не подавляются.

Удаление предварительно рассчитывает все затрагиваемые ID, включая изменения при завершении транзакции. При наличии зависимостей apply требует allowDependentDeletion=true. Если реальный набор удаления отличается от preview, группа откатывается.

Пробная транзакция отменяет изменения документа. Другие установленные надстройки могут реагировать на события Revit; их внешние действия не контролируются этим плагином.

## Ограничения

Листы: горизонтальный А3 420×297 мм, существующий тип основной надписи, копирование видов с оформлением. Прямоугольники видов проверяются на выход за рамку; проверка пересечений с основной надписью, подписями и таблицами выполняется визуально по PDF. Экспликация содержит помещения выбранного уровня с положительной площадью. Формат А3 сам по себе не означает соответствия ГОСТ: форма основной надписи, заполнение полей и содержание чертежей проверяются отдельно. Полный комплект рабочей документации автоматически не создаётся.

Двери/окна: OneLevelBasedHosted на прямых вертикальных базовых стенах без изменённого профиля, групп и присоединённых верха/низа. Проверяются стандартные ширина/высота, хост, уровень и точка. Проверка габаритов номинальная; нет проверки коллизий или нестандартного контура проёма.

Размеры: линейные, по явно указанным стабильным опорам; планы, разрезы, фасады, узлы и чертёжные виды. Связанные модели, угловые и дуговые размеры не поддерживаются. Марки — на планах этажей/потолков, пакетами до 50.

Графика: цвет линий и сплошной заливки, прозрачность, постоянное/временное скрытие и изоляция, сброс. Раскраска — до 1000 элементов и 100 групп; числовой градиент использует внутренние значения параметров.

Трубы и воздуховоды создаются прямыми сегментами из загруженных типов и систем; автоматической трассировки, фитингов и соединений нет. Кровля пока ограничена прямоугольным двускатным контуром. Балочные системы ограничены горизонтальным прямоугольником с фиксированным шагом и загруженным типом балки. Не все способы размещения семейств реализованы. Произвольное выполнение C#, облачное лицензирование, оплата и Яндекс ID не реализованы. Подробнее — SCOPE.md. Это самостоятельная разработка, не полная копия AIDrafting.

## Сборка и установка

Нужны Windows x64, Revit 2026, .NET 8 SDK/Windows Desktop Runtime, Node.js 20+ и pnpm либо npm.

```powershell
.\build.ps1
.\install.ps1
cd server
pnpm install --frozen-lockfile
pnpm test
```

При использовании npm выполните npm install и npm test. Для воспроизводимого набора зависимостей предпочтителен включённый pnpm-lock.yaml.

install.ps1 размещает DLL в %APPDATA%\Autodesk\Revit\Addins\2026\WEAM.Revit.AI\versions\0.9.6 и переключает .addin-манифест. Новая версия загрузится после перезапуска Revit. Предыдущая DLL сохраняется в своей папке. Повторная установка той же версии требует закрытого Revit.

В MCP-клиенте задайте command: node (либо полный путь к node.exe), args: полный путь к server/src/index.js, транспорт stdio, тайм-аут не менее 320 секунд. Пример для Codex — server/codex-mcp.example.toml. После изменения конфигурации перезапустите MCP-клиент, чтобы он перечитал список инструментов.

Мост слушает только IPv4 loopback. Локальный токен находится в %LOCALAPPDATA%\WEAM.Revit.AI\bridge.token; его нельзя публиковать. Снимки — в %LOCALAPPDATA%\WEAM.Revit.AI\snapshots. Данные, возвращённые MCP-инструментами, получает выбранный AI-клиент.
