# Область реализации — 0.9.6

Состояние ниже описывает исходный код. Полная проверка записи в Revit ещё не завершена; README.md содержит фактические результаты проверки.

| № | Возможность ориентира AIDrafting | Состояние |
|---:|---|---|
| 1 | Текущий вид и проект | Реализовано |
| 2 | Элементы текущего вида | Реализовано, выдача ограничена |
| 3 | Выделение | Чтение и выбор |
| 4 | Семейства и типы | Чтение; загрузка локального RFA; копирование типов дверей/окон с шириной и высотой |
| 5 | Поиск элементов | Фильтры, страницы, область, параметры; координаты размещения и отдельное чтение геометрических опор |
| 6 | Статистика | Базовые количества и категории |
| 7 | Данные помещений | Площадь, периметр, объём, уровень |
| 8 | Материалы | Площади/объёмы, без окрашенных поверхностей |
| 9 | Стены, балки, трубы, воздуховоды | Прямые стены и балки; прямые трубы и воздуховоды из существующих типов и систем, без трассировки и фитингов |
| 10 | Размещение семейств | OneLevelBased и двери/окна на прямых вертикальных базовых стенах; другие способы не реализованы |
| 11 | Перекрытия, потолки, крыши | Перекрытия и потолки; прямоугольные двускатные кровли |
| 12 | Оси | Прямые оси |
| 13 | Балочные системы | Горизонтальный прямоугольный контур, существующий тип балки, фиксированный шаг; ожидает проверку на живой модели |
| 14 | Уровни и планы | Уровни, планы этажей/потолков/конструкций |
| 15 | Помещения | Создание в замкнутых областях; линии разделения на планах |
| 16 | Точные размеры | Линейные цепочки по явным опорам, пробное создание и откат; без угловых/дуговых |
| 17 | Автоматические размеры между элементами | Нет автоматического подбора; доступны явные опоры пункта 16 |
| 18 | Марки стен | На плане этажа/потолка, существующий тип, до 50 |
| 19 | Марки помещений | На плане этажа/потолка; пропуск уже промаркированных, неразмещённых и незамкнутых |
| 20 | Выбор, видимость, графика | Выбор; цвет, прозрачность, скрытие/изоляция и сброс; нет 3D section box |
| 21 | Раскраска по параметрам | Палитра/числовой градиент, параметр экземпляра или типа |
| 22 | Удаление с зависимостями | Пробное удаление с откатом, список зависимостей, явное разрешение, проверка неизменности набора |
| 23 | Произвольный C# | Не включён согласно принятой области проекта |
| 24 | Сохранение данных проекта | Локальные JSON-снимки; сохранение текущего RVT или нового RVT; PNG-экспорт существующего вида |
| 25 | Сохранение данных помещений | Локальные JSON-снимки |
| 26 | Поиск сохранённых данных | Работает при закрытом Revit |
| 27 | Проверка связи | revit_ping, включая версию DLL |

Дополнительно: изменение параметров, переключаемое локальное автоподтверждение всех apply, отдельные значки обеих кнопок на панели Revit, создание горизонтальных листов А3 с копиями видов и экспликацией, компоновка видовых экранов, текстовые примечания, разрезы и PDF-экспорт листов. Форма основной надписи и соответствие оформления ГОСТ проверяются отдельно. Русский интерфейс команд; настройки языка, лицензирования, оплаты и подключения аккаунтов отсутствуют.
