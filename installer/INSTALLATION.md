# Установка WEAM.Revit.AI

1. Сохраните проекты и закройте Revit. Запустите `WEAM.Revit.AI-0.9.9-Setup.exe` обычным двойным щелчком.
2. Проверьте папку Autodesk Revit 2026. Выберите подключение Codex и/или Claude Desktop, если пользуетесь ими. Автоподтверждение можно включить здесь либо кнопкой плагина.
3. Нажмите «Установить». Запустите Revit и перезапустите AI-клиент. Если Revit спросит о загрузке WEAM, разрешите загрузку доверенной надстройки.
4. Проверьте командой MCP `revit_ping`. После успешного ответа можно читать модель и выполнять доступные инструменты.

Установка для текущего пользователя, без администратора. Поддерживается Windows x64 с установленным Revit 2026. Revit других версий и ARM64 не поддерживаются этой сборкой. Лицензия Autodesk приобретается отдельно. Установщик содержит Node.js, MCP-зависимости и собственную среду .NET; SDK, Python, npm и отдельная установка Node.js не нужны. Во время установки интернет не требуется.

Программа: `%LOCALAPPDATA%\WEAM.Revit.AI\Application`. Манифест: `%APPDATA%\Autodesk\Revit\Addins\2026\WEAM.Revit.AI.addin`. Готовые конфигурации другого MCP-клиента: `Application\versions\0.9.9\connection`. Не изменяйте путь к серверу при копировании этих конфигураций.

Установщик обновляет только MCP-запись `weam_revit_ai`, сохраняя другие серверы. Предыдущие конфигурации и манифест сохраняются в `%LOCALAPPDATA%\WEAM.Revit.AI\backups`. Повторный запуск восстанавливает файлы. Версии программы хранятся отдельно, чтобы обновление не заменяло Node.js, открытый старым клиентом. После обновления перезапустите клиент.

Удаление: «Параметры Windows → Приложения → Установленные приложения → WEAM.Revit.AI». Предварительно закройте Revit и MCP-клиент. Удаляются файлы программы и только принадлежащее ей подключение; RVT, снимки, токен, настройки и резервные конфигурации сохраняются. Старая ручная установка в каталог Addins не удаляется автоматически, но манифест переключается на новую сборку.

Лицензия собственного кода — AGPL-3.0-only. Соответствующие исходники включены в `source/WEAM.Revit.AI-0.9.9-source.zip`, также распространяются рядом с установщиком. Лицензии Node.js и MCP-пакетов сохранены в поставке. Autodesk DLL и модели в установщик не включены.

Сборка пока не подписана сертификатом издателя. Windows может показывать неизвестного издателя. Подпись сертификатом — отдельный этап подготовки публичного релиза.

Автоматическая установка: `Setup.exe --silent --codex --claude --auto-confirm`. Каждый флаг клиента необязателен; без них настройки клиентов не меняются. Для нестандартного каталога: `--revit="D:\Autodesk\Revit 2026"`. Код возврата 0 означает успех, 1 — ошибку; диагностика — `%LOCALAPPDATA%\WEAM.Revit.AI\setup.log`.
